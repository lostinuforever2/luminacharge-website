This portfolio brings together my Luminacharge project information and AIT classwork.

Website purpose

The website presents my Luminacharge product concept and organises supporting schoolwork in one place. It allows a visitor to explore the project, see classwork completed during lessons, and find the references used.

Website structure

The navigation is consistent across the pages: Home, Project, Assessments, Classwork and References. Each page has a clear heading and uses the same external stylesheet for its colours, typography and layout.

Accessibility and usability

  • Responsive layout for smaller screens
  • Readable contrast and consistent navigation
  • Semantic headings and labelled navigation
  • Classwork presented in a clear table
